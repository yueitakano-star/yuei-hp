# 事業の再編とサブドメイン新設 設計書

- 作成日: 2026-10-02
- 前提設計: 2026-09-23-yuei-corporate-site-design.md

## 0. 目的と成功基準

遊栄JAPANコーポレートサイト（https://yuei-japan.com）を、**Web開発・動画／静止画の広告物・ホームページ制作を主力とする仙台の会社**として見せる形へ作り変える。ナイトエンターテインメントの印象は弱め、事業一覧の最後に置く。

成功基準:
- トップ・事業一覧・ナビで、事業が ①Web・広告制作 → ②デジタルサイネージ → ③飲食 → ④ナイトエンターテインメント の順に並ぶ。
- Web・広告制作事業、トップ、理念、会社概要のコピーから「国分町」が外れ、仙台軸になる。サイネージ事業・ナイト事業・会社の住所は「国分町」表記のまま使う。
- サブドメイン `web.yuei-japan.com`（別プロジェクト、サブ2）への導線が用意されている。
- `pnpm typecheck && lint && test && build && e2e` が通り、Vercel プレビューで確認できる。

## 2. 決定事項

- **サービスブランド**: 「ケヤキクリエイト / KEYAKI CREATE」。ブランド名に「遊栄」を含めない。同業への配慮のため。
- **ドメイン**: 当面は `web.yuei-japan.com`。新規ドメインは取得しない。将来の独自ドメイン移行に備え、サイトの公開 URL は環境変数（サブ2側の `NEXT_PUBLIC_SITE_URL` 相当）で切り替えられるようにする。
- **運営者表記**: 運営会社名は、特定商取引法・プライバシーポリシー等の法的に必要な箇所とフッターの会社概要にのみ記載する。ヘッダー、ロゴ、本文には出さない。
- **本体サイト側**: 本体では遊栄が運営していると分かる形で、Web・広告制作事業として載せ、ケヤキクリエイトへリンクする。
- **事実情報**: 実績・料金・制作事例を推測で書かない。サンプル制作物は必ず「サンプル」と明記する。

## 3. サブ1の変更内容

### 3.1 事業の並びと名称
`content/businesses/*.json` の `order` を次のとおり振り直す。

| order | slug | 名称（案） |
|---|---|---|
| 1 | digital | Web・広告制作事業（ブランド: ケヤキクリエイト / KEYAKI CREATE） |
| 2 | signage | デジタルサイネージ事業（ブランド: 遊栄ビジョン / YUEI VISION、既存のまま） |
| 3 | dining | 飲食事業 |
| 4 | nightlife | ナイトエンターテインメント事業 |

- `slug` は変更しない（URL 互換性、既存テスト・sitemap への影響を避ける）。表示名、`nameEn`、`brand`、`brandEn`、`titleDisplay` だけを更新する。`titleDisplay` から `|` を除いた文字列は `brand ?? name` と一致させる（`BusinessSchema` の refine 制約）。
- `company.json` の `businessSummary` も同じ順に並べ替える。
- digital の `services` を「ホームページ制作」「動画・静止画の広告物」「Webシステム・AI活用」「運用・改善」に再構成する。`flow`（5 ステップ）は維持し、広告物制作にも読めるよう文言を調整する。

### 3.2 国分町色の除去
- Web・広告制作事業と飲食事業の `lead`・`description`、`company.json` の `philosophy` と `greeting`、トップの各セクション、`app/layout.tsx` のメタ情報から「国分町」を外し、「仙台」「街」「地域」に置き換える。
- 国分町表記を維持する箇所: 会社概要の住所、サイネージ事業（概要文・設置場所）、ナイト事業（説明・店舗ページ）。これらは書き換えない。
- 理念: 「仙台から、街と企業の未来へ。」（承認済み）。`greeting` は `draft: true` を維持し、書き換えは案として提示する。
- ナイト事業は並びを最後にするだけで、説明と店舗ページ（KINGYO / B-club / C-girl）の文言は変えない。トップでの画像の露出は抑える。

### 3.3 トップとナビ
- `components/sections/home/` のヒーロー、`businesses-prism`、`business-marquee`、`numbers`、`signage` を新しい並びと文言に合わせる。ナイトは最後尾に置き、画像の露出も抑える。
- トップと digital 事業ページに、ケヤキクリエイト（`web.yuei-japan.com`）へのリンクを置く。サブ2公開前は、リンク先を環境変数で有効化するまで非表示にする（死んだリンクを出さない）。

### 3.4 テストと検証
- `tests/`（content, sections, seo）と `e2e/` のうち、並び順や文言に依存する箇所を更新する。
- 検証は `pnpm typecheck && pnpm lint && pnpm test && pnpm build && pnpm e2e` のすべて。その後 PR を作り、Vercel プレビューで確認してからマージする（main への直接コミットはしない）。
- 本番反映後は `curl` で https://yuei-japan.com の実測（HTTP ステータス、sitemap、事業順序）を取る。

## 4. サブ2の概要（別設計書で詳細化）

- 構成: トップ / 制作サービス / 実績・サンプル / 料金 / 記事 / お問い合わせ。
- 日次記事: 一次情報の URL つきで生成し、公開前に URL の実在・捏造・重複を自動チェックする。実行環境（ローカルのタスクスケジューラ、または GitHub Actions）はサブ2の設計書で決める。
- サンプル制作物: Codex 画像生成と Photoshop でバナー、チラシ風の静止画、動画素材、サンプルサイトを制作する。
- DNS: `web` の CNAME を Vercel に向ける。Vercel CLI は認証済みのため、ドメイン追加と環境変数設定は実行まで行う。
