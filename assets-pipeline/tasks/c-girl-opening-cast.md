# オープニングキャストの飾り文字

ユーザー依頼: オープニングキャストも飾り文字で目立たせる。

現在のC-girl店舗ページのヒーローに「オープニングキャスト募集中」を追加。既存のZen Kaku Gothic Newの太字にプラムの縁取りとオーキッドの段差の影を組み合わせ、ネオンサインを連想する飾り文字にする。既存の色・書体トークンを使用し、写真や店名と重ならない通常フローで配置する。日本語は意味のある単位で折り返す。文字はHTMLで読み上げと選択を保ち、点滅させない。

案内全体から公式サイトの既存 `/recruit` へ遷移。給与など新しい条件は追加しない。
