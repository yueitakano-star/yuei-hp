# C-girlの店舗写真を横長に見せる

ユーザー依頼: 写真の切れ方を直し、もっと横長で広々見せる。

既存の色・書体は維持。細い縦枠と段違いの2列配置をやめ、店内写真をコンテンツ幅いっぱいの1列で配置する。PCは16:9、スマホは3:2で、元写真の左右を切らずに店内の横の広がりを見せる。ネオン写真はソファ席まで入る位置に合わせる。アクセス欄のカウンター写真は原寸比4:3で全体を表示する。
