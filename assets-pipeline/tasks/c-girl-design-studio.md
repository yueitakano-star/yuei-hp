# C-girl 店舗紹介ページのデザイン刷新

ユーザー依頼: フォントを含めてプロらしいデザインへ刷新する。既存と大きく変わってもよい。デザインスキルを導入し、必要な画像は生成する。

対象は直前に更新した `/business/nightlife/c-girl`。店舗情報・公式リンク・構造化データを保ち、店舗紹介としての印象と読みやすさを整える。

## デザイン方針

- 深いプラム `#21152e`、ペールライラック `#eee8f7`、オーキッド `#f0a9d8`、バイオレット `#665281`、ホワイト `#ffffff` を専用トークンとして定義。
- 欧文の店名は Righteous、日本語の見出しは Shippori Mincho。本文は既存の日本語サンセリフ。欧文の太い丸みと日本語の静かな組版を対比させる。
- ヒーローは大きな店名と、光・ガラス・ミラーボールの生成アート。実店舗の紹介には本物の店内写真を使う。
- 色面や写真を大きく使い、細かいカードやラベルを重ねない。動きは既存のナビゲーションに留める。
- 営業時間、地図、公式サイトへの導線を明快にする。確認できない料金や口コミは追加しない。

```
企業ヘッダー
深いプラムのヒーロー / 大きなC-girl / 右に光のアート
営業時間と所在地の簡潔な案内

店舗情報 / 地図と公式サイト

```

## 方針の見直し

スキルの最初の提案は一般的なホテル向けの金・青と透過UIだったため採用しない。ナイトバーの実際のネオン・光る壁を起点にし、生成画像も架空の店内ではなく装飾の静物とする。過度なアニメーションや汎用カードの反復は使わない。
